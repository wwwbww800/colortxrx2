利用螢幕發光色彩與相機空間差分特性的高穩定性 VLC 通訊架構

發射端 (Tx)

Color Transmitter

將輸入的中文字串透過 Unicode 編碼拆解為 Hex 色碼封包，並在螢幕上渲染色區進行光訊號發射。

接收端 (Rx)

Color Receiver

運用鏡頭捕捉螢幕色塊，透過動態比值校準與 Gamma 轉譯進行影像訊號解調並還原文字。

10/07 最新更新內容

  • 無因次比值計算： 接收端不再直接讀取 Raw RGB，改為以 n = (X - K) / (G - K) 為核心獨立計算每個 RGB 通道[cite: 1]。
    （$X$: 目標區塊、$G$: 參考灰階 [視為 1.0]、$K$: 參考全黑 [視為 0.0]。當相機曝光、白平衡或增益變動時，此比值能保持高度穩定[cite: 1]。）
  • 即時 Gamma 曲線建立： 利用傳輸前先送出的 16 階灰階校驗訊號，於接收端即時建立該螢幕的動態 Gamma 轉譯曲線[cite: 1]。

系統運作原理

1編碼與封包 (Encoding)

將中文轉為 Unicode 十進位數字（5或6位數，5位補 f）[cite: 1]。轉換為 Hex 色碼後切分為 2 個色碼封包（每個封包傳送 3 位數）[cite: 1]。

2空間差分傳送 (Spatial Differential)

假設原始色碼為 #808080，利用空間差分同時顯示兩色（RRGGBB 分別 +10 與 -10）[cite: 1]。同時附帶第三區塊固定灰階與第四區塊全黑基準[cite: 1]。

3訊號解調與校準 (Decoding & Calibration)

相機在固定曝光白平衡下擷取色塊，以全黑與固定灰階當作參考基準點進行色彩與 Gamma 修正，解出原始色碼並轉回 Unicode 文字[cite: 1]。
