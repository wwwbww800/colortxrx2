<br>
一個可見光色碼通訊系統
<br>
<br>
原理
<br>
將中文用unicode 轉為十進位後輸出成hex色碼（中文字unicode十進位 為5或6位數 若為5位數則第六位補f） 再將hex做成封包 每個封包傳送3位數 所以一個hex色碼會拆分成2個hex色碼來傳送 <br>解碼時再合併再讓螢幕依照那一個hex色碼 顯示成兩個顏色（編碼時將 RGB 的數據+10和-10（超過245或低於10自動溢位））  再讓相機測出那兩個色碼的值相機就可以得出兩串色碼 <br>再將那兩串色碼+10和-10就能得出原本輸出的hex色碼 套用unicode後就能接收到原始欲傳輸的文字<br>
