一個可見光色碼通訊系統
<br>

將中文用unicode 轉為十進位後輸出成hex色碼（中文字unicode十進位 為5或6位數 若為5位數則第六位補f） 再將hex做成封包 每個封包傳送3位數 所以一個hex色碼會拆分成2個hex色碼來傳送 <br>解碼時再合併再讓螢幕依照那一個hex色碼（假設#808080） 用空間差分同時顯示兩個顏色 例如把#808080的RRGGBB都減10和加10（十進位） 再讓相機測出那兩個色碼的值（相機曝光和白平衡都固定 螢幕亮度固定） 相機就可以得出兩串色碼 <br>編碼時將 RGB 的數據（超過245讓他溢位 低於10同理） 再把那兩串色碼一個+10一個-10就可以得出原本的加密之後輸出成的hex色碼 套用unicode後就能接收到那串文字<br> 第一次傳輸訊號前先傳輸一個校驗訊號 （16階灰階） 讓發射端和接收端都知道 再用這個來校準<br> 每一個封包（兩個顏色）要同時顯示一個固定的灰階在第三個區塊和一個全黑的黑色在第四區塊 當作接收端每次接收的參考值
